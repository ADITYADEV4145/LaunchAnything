All 15 channel planning windows currently use Tuesday–Thursday, 09:00/14:00 in your configured timezone. They are heuristics, not measured optimal posting times.

## Route boundaries

Normal publish previews, and --confirm stages local files. API/Postiz/Buffer/Ayrshare-named adapters currently stage offline files, not API posts. Official PH MCP creates drafts/readiness previews only; X MCP has no verified post-create tool. Browser assist fills HN/Reddit/PH forms but never submits; LinkedIn website automation is forbidden. Kit is a local waitlist/import workflow plus optional credential storage, not an email sending integration. All routes require human control and exact-content approval.

Each page links the planning and platform YAML plus implementation sources, and includes applicable route troubleshooting. See [LaunchBench](../../bench/launchbench/README.md) for human evaluation, not claims about automated posting success.
