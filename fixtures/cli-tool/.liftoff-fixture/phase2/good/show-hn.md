My daily task list kept getting buried under setup I did not need. Tasklight is a small terminal checklist for that. The CLI adds and lists tasks in a local JSON file, so you can read or diff it. It runs with Node and needs no account. Try it from the repository: https://github.com/ADITYADEV4145/LaunchAnything/tree/main/fixtures/cli-tool

## First comment outline

- Why I made it: every to-do app I tried wanted an account before the first task.
- How it works: one JSON file next to your code, plain commands to add and list.
- What it does not do yet: no sync between machines and no due dates.
- What I want to know: which command name felt awkward?
